### 在做什么

- **AI 工具** —— 把长视频、法律条文、资讯流变成可读、可检索的东西
- **桌面工具** —— 截图、整理、自动化，先解决自己每天遇到的问题
- **本地优先** —— 能跑在自己机器上的，就不依赖云
